# 🇰🇷 Korean Name Generator

외국인과 한류 팬을 위한 한국 이름 생성기! K-pop과 K-drama를 사랑하는 전 세계 팬들이 자신만의 특별한 한국 이름을 찾을 수 있습니다.

## ✨ 주요 기능

- 🎭 **성별 선택**: Male, Female, Non-binary
- 🎨 **스타일 선택**: Traditional, Modern, Trendy
- 🌟 **테마 선택**: Nature, Wisdom, Strength, Beauty, Virtue
- 🔤 **발음 가이드**: 로마자 표기 제공
- 💡 **의미 설명**: 각 이름의 영어 의미
- 🎯 **추천 이름**: 유사한 이름 3개 제안
- 📋 **클립보드 복사**: 원클릭 복사

## 📊 데이터

- **30개 성씨** + **120개 이름** = **3,600개 조합**
- 모든 이름에 발음, 의미, 스타일, 테마 포함

## 🚀 시작하기

```bash
npm install
npm run dev
```

## 🛠️ 기술 스택

- Next.js 15.5.4 (App Router)
- TypeScript
- Tailwind CSS
- Turbopack
